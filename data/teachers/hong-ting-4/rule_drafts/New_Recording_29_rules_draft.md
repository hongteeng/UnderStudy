# Draft tutor rules: Why oxidising agents are reduced

## Student-request types and recognition cues

- **Conceptual “why” question about redox-agent behaviour:** Recognise questions such as “Why is an oxidizing agent always reduced?” as asking for the relationship between the agent’s effect on another substance and the change undergone by the agent itself. (New_Recording_29.md)

## Tutor response approaches

- Begin by establishing the central redox principle: reduction and oxidation must both occur in a redox reaction. (New_Recording_29.md)
- Next, define an agent according to what it causes another substance to undergo: an oxidising agent causes another substance to be oxidised, while a reducing agent causes another substance to be reduced. (New_Recording_29.md)
- Then connect the other substance’s change to the agent’s own change: if the other substance is oxidised, the oxidising agent is reduced; if the other substance is reduced, the reducing agent is oxidised. (New_Recording_29.md)
- Use informal personification—“one guy,” “the other guy,” or “another person”—to make the paired nature of redox intuitive before restating the scientific relationship. (New_Recording_29.md)

## Required and preferred vocabulary

- State that **reduction and oxidation must both happen** in a redox reaction. (New_Recording_29.md)
- Define an **oxidising agent** as a substance that “cause[s] other people to be oxidised”; in formal wording, it causes another substance to be oxidised. (New_Recording_29.md)
- Define a **reducing agent** as a substance that “cause[s] another person to be reduced”; in formal wording, it causes another substance to be reduced. (New_Recording_29.md)
- State the paired conclusions explicitly: **an oxidising agent is reduced**, and **a reducing agent is oxidised**. (New_Recording_29.md)

## Wording to avoid or qualify

- Avoid leaving the explanation at the informal “99% of the time” phrasing. For the defining redox relationship, use the tutor’s firmer conclusion that reduction and oxidation occur together and that a reducing agent “will always be oxidized”; apply the corresponding relationship to an oxidising agent being reduced. (New_Recording_29.md)
- Do not define an oxidising or reducing agent by what happens to the agent itself alone. First define it by what it causes to happen to the other substance, then explain the agent’s own change. (New_Recording_29.md)

## Topic map and reusable explanations

- **Paired processes:** Redox cannot contain reduction without oxidation; “reduction and oxidation must both happen.” (New_Recording_29.md)
- **Oxidising agent:** It causes the other substance to be oxidised. Because oxidation must be accompanied by reduction, the oxidising agent is reduced. (New_Recording_29.md)
- **Reducing agent:** It causes the other substance to be reduced. Because reduction must be accompanied by oxidation, the reducing agent is oxidised. (New_Recording_29.md)
- **More than two reactants:** One reactant may be reduced, another oxidised, while a third undergoes no redox change. (New_Recording_29.md)
- **Redox within one reactant:** Different elements in one reactant may undergo the two changes, with one element reduced and another oxidised. The essential point remains that both processes occur. (New_Recording_29.md)

## Analogies and examples to reuse

- Personify the reacting substances: “You cannot have one guy being reduced and then don’t want to be oxidised.” Use this to show that if one participant is reduced, another must be oxidised. (New_Recording_29.md)
- Describe the agent as acting on “the other person”: the oxidising agent causes the other person to be oxidised, while the reducing agent causes the other person to be reduced. (New_Recording_29.md)
- For a reaction with three reactants, explain that one may be reduced, one oxidised, and the third may have “nothing happen” in redox terms. (New_Recording_29.md)

## Misconceptions to pre-empt

- Pre-empt the idea that reduction can happen by itself: in a redox reaction, oxidation must happen alongside it. (New_Recording_29.md)
- Pre-empt confusion caused by the agent’s name: an oxidising agent is named for causing oxidation in another substance, not because the agent is itself oxidised. It is reduced. Likewise, a reducing agent causes reduction and is itself oxidised. (New_Recording_29.md)
- Pre-empt the assumption that every reactant must change oxidation state: where there are three reactants, one may undergo no redox change. (New_Recording_29.md)
